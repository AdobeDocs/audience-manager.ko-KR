# 암호 요구 사항, 잠긴 계정 및 잊어버린 암호{#password-requirements-locked-accounts-and-forgotten-passwords}

30일마다 암호를 만료하도록 Audience Manager를 구성할 수 있습니다. 암호 만료를 사용하려면 Audience Manager 컨설턴트나 고객 지원 센터에 이야기하십시오. 암호 요구 사항 및 분실했거나 기억나지 않는 암호를 복구하는 방법을 알려면 이 섹션을 참조하십시오.

**암호 요구 사항**

[!DNL Audience Manager] 암호가 유효하려면 다음 요구 사항을 충족해야 합니다.

| 요구 사항 | 설명 |
|---|---|
| 길이 | 암호는 12-40자일 수 있습니다. |
| 내용 | 암호는<ul><li>영숫자로 시작하고 끝나야 합니다.</li><li>대문자와 소문자를 각각 하나 이상 포함해야 합니다.</li><li>숫자를 하나 이상 포함해야 합니다.</li><li>특수 문자를 하나 이상 포함해야 합니다(콜론 제외).</li><li>라틴 알파벳으로만 구성해야 합니다.</li></ul> |
| 버전 | 암호는 이전 12개의 암호와 달라야 합니다. |
| 금지 사항 | 암호에는 다음이 포함되지 않아야 합니다.<ul><li>이름 또는 성.</li><li>전자 메일 주소 또는 [!DNL Adobe] 사용자 ID입니다.</li><li>연속 문자 또는 숫자.</li><li>순차적 문자 또는 숫자.</li><li>일반적으로 사용되는 암호.</li></ul> |

암호 재설정에 대한 자세한 내용은 [계정 설정 편집](../features/administration/edit-account-settings.md)을 참조하십시오.

**계정 잠금**

보안을 위해 [!DNL Audience Manager]에서 일시적으로 실패한 로그인 시도에 대한 요율을 제한합니다. 한도를 초과하면 [!DNL Audience Manager]에서 짧은 기간 동안 추가 로그인을 차단한 다음 자동으로 다시 허용합니다. 계정 잠금을 해제하기 위해 관리자 또는 파트너 서비스 담당자에게 문의할 필요가 없습니다.

**분실했거나 기억나지 않는 암호**

암호를 재설정하려면 로그인 페이지에서 **[!UICONTROL Forgot password]**&#x200B;을(를) 선택하십시오. [!DNL Audience Manager]에서 암호를 재설정할 수 있는 링크가 포함된 전자 메일을 보냅니다. 링크를 선택한 다음 암호 요구 사항에 맞는 새 암호를 만듭니다. 링크는 한 번만 작동합니다.

**새 계정 설정**

관리자가 계정을 만들 때 [!DNL Audience Manager]에서 암호를 설정할 수 있는 링크가 포함된 전자 메일을 보냅니다. 링크를 선택한 다음 암호 요구 사항을 충족하는 암호를 만듭니다. 처음 로그인하려면 먼저 암호를 설정해야 합니다.
